# Sunset City

An original, fan-made open-world crime sandbox that runs entirely in the browser. No commercial game assets are used: the city, cars, characters, interface, and synthesized audio are generated by this project's own code.

> Unofficial tribute. Not affiliated with or endorsed by Rockstar Games.

## Play

The project is a static site with ES modules, so serve it over HTTP rather than opening `index.html` directly.

```bash
python3 -m http.server 3002
```

Then open <http://localhost:3002>.

## Controls

| Input | On foot | In a vehicle |
| --- | --- | --- |
| `WASD` / arrow keys | Move | Drive / steer |
| `Shift` | Sprint | Handbrake |
| `E` | Enter a nearby vehicle | Exit (when slow) |
| `F` / click | Shoot | — |
| `Esc` / `P` | Pause / resume | Pause / resume |
| `M` | Mute | Mute |

On phones and tablets, a virtual joystick, `ENTER`, `FIRE`, and `BRAKE` buttons appear automatically.

## Features

- Procedurally generated city with parks, parking lots, rooftop details, street furniture, and traffic.
- On-foot exploration, carjacking, driving physics, collisions, and chases.
- Pedestrians, police response, a five-star wanted system, and wanted-level cooldown.
- Repeatable courier and vehicle-repo jobs, cash pickups, health, damage, and respawning.
- Minimap, objective markers and direction arrow, synthesized engine/siren/SFX audio.
- Responsive HUD and touch controls, plus a cached static city layer for smoother rendering.

## Source layout

- `index.html`, `styles.css` — shell, HUD, menus, overlays, and responsive styling.
- `js/game.js` — game state, input actions, player/camera, driving.
- `js/world.js` — city generation, collision, static city rendering.
- `js/systems.js` — traffic, pedestrians, police, missions, pickups, particles.
- `js/render.js` — world/entity rendering, markers, cached ground layer, screen feedback.
- `js/hud.js` — DOM HUD and minimap.
- `js/input.js` — keyboard, mouse, and touch input.
- `js/audio.js` — synthesized Web Audio engine, siren, and effects.
- `js/main.js` — bootstrap and animation loop.

## Serve with the provided runner

If the workspace runtime provides one, `./start.sh` starts the project on the configured port.
